# Result files

This directory contains compact, machine-readable summaries and human-readable
reports. Per-seed prediction tensors and per-chain probability archives are
not committed.

## Data audit

- `raw_inventory.json`: raw input counts and parsing checks
- `raw_input_sha256.json`: hashes of the copied raw files
- `exact_duplicate_groups.json`: exact-sequence groups
- `conflicting_sequence_families.csv`: sequence-identical groups with label variation
- `dedup_summary.json`: split counts, policies and manifest hashes
- `removal_ledger_*.csv`: itemized removal ledgers
- `validation_report.json`: machine-checked invariants
- `AUDIT_REPORT.md`: generated audit summary

## Main protocol

- `large_protocol/analysis.json`: primary model summaries and paired tests
- `large_protocol/structure_ensembles.json`: structure-aware ensemble controls
- `large_protocol/large_p80_cv5_audit.json`: fold and component audit
- `large_protocol/LARGE_PROTOCOL_RESULTS.md`: readable result report

## Follow-up analyses

- `followup/all_metric_stats/all_metrics.json`: all metrics and bootstrap results
- `followup/size_curve/size_curve.json`: fixed-composition training-size curve
- `followup/repeated_cv/analysis.json`: alternative homology-aware partitions
- `followup/shuffled3d/analysis.json`: shuffled-3D topology control
- `followup/grasp_grid/analysis.json`: GRASSP sensitivity grid
- `followup/duplicate_weighting/analysis.json`: redundancy-weighting ablation
- `followup/FOLLOWUP_RESULTS.md`: readable follow-up report

The Markdown reports summarize the JSON result files and are generated by the
analysis scripts in `scripts/`.
