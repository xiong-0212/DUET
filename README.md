# DUET

DUET is a sequence-only ensemble for residue-level RNA-small-molecule binding-site
prediction. This repository contains the current test-clean, redundancy-aware
rebuild, the complete training and analysis pipeline, and compact result
summaries.

## Current protocol

- RNA sequence and predicted secondary structure only
- Frozen RNA-FM and RiNALMo encoders
- Relational graph tower plus TCN and DenseNet sequence towers
- 80% global sequence-identity components for training and cross-validation
- Five homology-aware folds and ten paired training seeds
- Cross-test exact-duplicate removal and explicit test-homology filtering
- Chain-level resampling for uncertainty analyses

## Repository layout

```text
configs/                         Protocol configuration
src/duet_clean/                  Data curation, training and analysis code
src/duet_model/                  Model components
scripts/                         End-to-end pipeline entry points
tests/                           Unit and protocol tests
data/raw/                        Small CoBRA source tables
data/clean/manifests/            Audited split manifests and hashes
data/external/                   Small external-set metadata
results/                         Compact JSON and Markdown result summaries
checkpoints/                     Local checkpoint directory, not committed
```

Processed graph tensors, model checkpoints, per-seed prediction archives and
logs are intentionally excluded from Git. They are regenerated by the pipeline
and are too large for a normal repository.

## Installation

Python 3.9 or newer is required. Install the PyTorch and PyTorch Geometric
build that matches the local CPU or CUDA runtime first, then install the
remaining dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Data

The raw CoBRA tables are in `data/raw/cobra`. The audited training manifests are
in `data/clean/manifests`.

The large-protocol manifest is `data/clean/manifests/large_p80_cv5.json`.
It defines the 290-record test-clean pool, whole-component folds and the
canonical test sets used for all reported experiments.

Precomputed RNA-FM and RiNALMo embeddings are not stored in Git. If they are
available locally, point the external builder to their directory:

```powershell
$env:DUET_EXTERNAL_EMBEDDINGS = "path\to\external\embeddings"
```

ERNIE-RNA weights are likewise external to the repository:

```powershell
$env:ERNIE_RNA_DIR = "path\to\ernierna"
```

## Reproduce

Run the data build and tests:

```powershell
.\run_all.ps1
```

Run the main large-data protocol:

```powershell
.\run_large_protocol.ps1
```

Run the reviewer-facing robustness and ablation analyses:

```powershell
.\run_followup.ps1
```

The scripts accept an explicit interpreter when `python` is not on `PATH`:

```powershell
.\run_large_protocol.ps1 -Python "path\to\python.exe"
```

Protocol details are documented in `PROTOCOL.md` and
`PROTOCOL_LARGE.md`. Compact numerical outputs are under `results/`.

## Source-count weighting

Each 80% identity component contributes one unit of total training weight.
This prevents sequence-identical records from receiving unbounded extra weight
while retaining all audited labels and records.
